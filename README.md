# timbrr-community

The blocks every [Timbrr](https://github.com/thriftrr/timbrr) site can use,
as a Nuxt layer: one definition and one Vue component per block, the
manifest a Timbrr studio reads to edit them, and the canvas page the
studio's builder frames — so what you build in the studio is drawn by the
same code the site serves.

Start with [docs/README.md](docs/README.md). The wire contract between a
site and a studio is [docs/manifest.md](docs/manifest.md).

Apache-2.0.
